# Security Policy

## Supported Versions
This project is in active development. Only the latest code on the default branch is supported for security fixes.

## Reporting a Vulnerability
Please report security issues privately so we can fix them before disclosure.

Preferred contact:
- Email: security@your-domain.example (replace with your real address)

Include:
- A clear description of the issue
- Steps to reproduce
- Impact and affected components
- Any suggested remediation

## Disclosure Process
We aim to:
- Acknowledge receipt within 72 hours
- Provide a status update within 7 days
- Release a fix as soon as reasonably possible

## Coordinated Disclosure
Please do not open public issues for security reports. We will coordinate a public disclosure once a fix is available.
